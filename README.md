# Измерение габаритов товара на конвейере

Учебный прототип для тестового задания мастерской Ozon, трек «Компьютерное
зрение». Проект показывает базовую версию алгоритма без настоящих сенсоров:
создаёт синтетические данные двух лазерных профилометров, добавляет ленту,
шум и выбросы, а затем восстанавливает длину, ширину и высоту товара.

![Результат демо](demo_output/demo.png)

## Что реализовано

- имитация двух встречных лазерных профилометров;
- модель горизонтальной конвейерной ленты;
- гауссов шум, пропуски и одиночные выбросы;
- удаление точек ленты;
- radius-фильтр выбросов на пространственной сетке;
- 2D-выпуклая оболочка алгоритмом монотонной цепи;
- минимальный прямоугольник в XY методом вращающихся калиперов;
- высота от известной плоскости ленты;
- quality gate и статус `REJECT` при плохих данных;
- JSON, CSV и SVG с результатом;
- unit-тесты и GitHub Actions.

## Быстрый запуск

Нужен Python 3.10 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
ozon-dim-demo
```

Можно запустить и через файл:

```bash
PYTHONPATH=src python run_demo.py
```

После запуска в папке `demo_output/` появятся:

- `demo.svg` — изображение исходных и очищенных данных;
- `result.json` — размеры, ошибка и результат проверки допуска;
- `filtered_points.csv` — очищенное облако точек.

Пример вывода:

```text
Статус: OK
Эталон L/W/H, мм:    200.00 / 100.00 / 40.00
Измерено L/W/H, мм:  около 201 / 101 / 41
Абс. ошибка, мм:     меньше 5 мм по каждой стороне
В допуске: ДА
```

## Свои параметры

```bash
ozon-dim-demo \
  --length 300 \
  --width 120 \
  --height 80 \
  --yaw 35 \
  --seed 10 \
  --output-dir my_demo
```

Критерий из задания проверяется отдельно по каждой стороне:

```text
abs(measured - truth) <= max(5% * truth, 5 мм)
```

## Тесты

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```

Тесты проверяют:

- размеры повёрнутого прямоугольного объекта;
- перестановку длины и ширины;
- удаление одиночного выброса;
- измерение полного синтетического прохода;
- отказ на пустой ленте;
- отказ, если от второго сенсора пришло слишком мало данных.

## Как работает алгоритм

1. Облака двух сенсоров переводятся в систему координат ленты.
2. Точки около `z = 0` считаются лентой и удаляются.
3. Одиночные 3D-точки удаляются radius-фильтром.
4. Точки проецируются на плоскость XY.
5. Для проекции строится выпуклая оболочка.
6. По рёбрам оболочки ищется прямоугольник минимальной площади.
7. Высота берётся от ленты до максимальной точки товара.
8. Результат сравнивается с допустимым диапазоном и сохраняется в JSON.

Подробности находятся в [docs/ALGORITHM.md](docs/ALGORITHM.md).

## Почему здесь нет Open3D

В отчёте для промышленной версии предлагается Open3D `MINIMAL_JYLANKI`, который
может искать OBB в полной 3D-ориентации. В базовом демо специально оставлена
простая реализация на NumPy: её легче запустить и объяснить на защите.

Ограничение: ось высоты считается перпендикулярной ленте. Для большинства
товаров, лежащих на конвейере, это разумное упрощение. Если предмет может быть
сильно наклонён по трём осям, функцию `constrained_obb` нужно заменить на полный
3D-алгоритм.

## Подключение реальных Gocator

Синтетический генератор заменяется адаптером LMI SDK. Для каждого профиля надо:

1. получить `x`, `z`, intensity и encoder tick;
2. вычислить `y = tick * mm_per_tick`;
3. применить матрицу `T_sensor_to_belt`;
4. передать массив `(N, 3)` в `measure_object`.

Формат следующего слоя уже не зависит от модели сенсора.

## Структура проекта

```text
src/ozon_dimension_demo/
  geometry.py       геометрия, hull, OBB и фильтр
  pipeline.py       обработка и quality gate
```

## Важно

Это базовая учебная версия, а не готовая система безопасности. Перед установкой
на реальный конвейер нужны калибровка, проверка лазерной безопасности и испытания
на настоящих упаковках, особенно прозрачных, зеркальных и очень тёмных.
